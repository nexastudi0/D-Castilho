D-CASTILHO - PREPARO iOS NO WINDOWS

1. Suba TODO o conteúdo desta pasta para a raiz do repositório GitHub D-Castilho.
2. Confirme que codemagic.yaml aparece na raiz do repositório (ao lado de package.json).
3. No Codemagic, branch main, clique em "Check for configuration files".
4. O workflow "D-Castilho iOS" deverá aparecer.
5. Inicie o primeiro build. Ele gera uma compilação de SIMULADOR sem assinatura Apple, usada para validar que o projeto iOS compila corretamente.
6. Depois do primeiro build aprovado, configure Apple Developer/App Store Connect no Codemagic para gerar um .ipa assinado e enviar ao TestFlight/App Store.

IMPORTANTE:
- O app usa o conteúdo da pasta www.
- O banco Supabase existente foi mantido.
- Não publique chaves secretas/service_role no JavaScript do app. Chave publishable/anon é a apropriada para cliente, com RLS configurado no Supabase.
